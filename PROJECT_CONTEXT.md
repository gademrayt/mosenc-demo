# Mosenc — новый ручной маршрут

## Решения Витальки
- Новый проект с чистого старта, с учётом накопленных материалов, без удаления старых попыток.
- Виталька сам делает и учится. Hermes придумывает последовательность и помогает с проверкой; Antigravity подключается точечно. Не заменять обучение автономной сборкой без просьбы.
- Не повторять длинный общий курс Mastery: короткие действия по реальному сайту, видимый результат, минимум предварительной теории.
- Сначала русское локальное демо для показа шефу. Каталог кофе, услуги, телефон и форма заявки. Сотрудники подтверждают заказ и готовят к получению; клиент приезжает, платит на заводе и забирает.
- Без онлайн-оплаты и доставки сейчас. Онлайн-продажи — возможный отдельный будущий этап.
- Позже LV и EN, основной LV, порядок LV → EN → RU.
- План в HTML с сохраняемыми галочками, заметками, переносом прогресса. Размещение: `C:\Users\vital\Desktop\Codex\Mosenc-WordPress-Plan`.
- Git/GitHub и, вероятно, Vercel обсуждались как возможности, а не разрешение на немедленную публикацию.
- Вопросы только по одному и после проверки уже предоставленных источников.

## Как продолжать
Открой `index.html`. Для сверки прогресса попроси свежий JSON-экспорт или текущий ID. Не делай вывод по файлу HTML: личные отметки находятся в браузере. Не угадывай, какие шаги выполнены.

Если помогает Codex/Antigravity: сначала прочитать этот контекст и выбранную задачу в `src/plan.json`; затем одно действие с проверкой. Не выдавать весь маршрут повторно.

## Рекомендации плана, ещё не факт установки
- Kadence Theme + Kadence Blocks / Gutenberg, один способ сборки, проверка совместимости перед установкой.
- Прототипы — визуальные и контентные источники, не готовая тема. Конкретный визуальный эталон выбирается в M05.
- Для раннего маленького демо допустимы ручные страницы кофе; до выпуска нужен единый источник данных карточек (M22).
- Новый изолированный WordPress ещё предстоит подготовить; порт, Compose project, пути и тома не назначены наугад.

## Что создано / что нет
Создан только рабочий HTML-план, отдельный обзор для шефа, исходники и проверки. Старые проекты/учебные статусы не изменены. WordPress/Docker не запускались и не перенастраивались. GitHub/Vercel/production не изменялись. Тестовые отметки использовались только в изолированных браузерных профилях.

## Источники
Карта и ограничения прочитанного находятся в конце HTML и в `src/plan.json` (S1–S12). В том числе свежий Mastery brief, прототип RigaKafa-KafijasDraugs, его технический аудит, Pipeline, тематические Obsidian-заметки, EVGESHA-контекст, WPBeginner и официальные страницы WordPress. Книга проверена по оглавлению, не прочитана целиком. Не утверждать, что все файлы во всех папках исследованы.

Новые решения пользователя важнее старых Django/Elementor/Kadence, портов и языковых режимов из архивов. Текущий маршрут проекта независим от исторического журнала Mastery; старые достижения сохраняются как учебная история, а не автоматически выполненные шаги нового сайта.
