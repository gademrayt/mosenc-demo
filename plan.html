Как работать с планом — коротко

Продолжаем, а не начинаем заново

WordPress уже существует. Проверяем только недоказанные пункты и продолжаем сборку. Старые проекты, исходники и принятые задания Mastery сохраняем; общий курс заново не проходим.

Рабочая сборка: http://localhost:8108/. Выбраны WordPress + Kadence Theme + Kadence Blocks + WooCommerce. Путь среды, изоляция и резервные копии требуют отдельной проверки.

Одна сессия — видимый результат

Открой первый незавершённый шаг → сделай → проверь по критерию → оставь заметку → поставь галочку → экспортируй отметки. Если не получается — запиши конкретный блокер и попроси одно следующее действие.

План — основной журнал этого нового проекта. Mastery остаётся справочником, без автоматической синхронизации статусов.

  • Сейчас: русский сайт, каталог, услуги, телефон и заявка, оплата/получение на заводе.
  • Позже: основной LV, затем EN, затем RU; всё содержание и сообщения без смеси языков.
  • Не сейчас: онлайн-оплата, доставка, аккаунты, фильтры ради красоты, обязательный PHP-курс, конвейер из всех AI.
  • Стек выбран: WordPress + Kadence + Kadence Blocks + WooCommerce. Товары сразу в WooCommerce, без ручных дублей и будущей смены движка. Короткая форма без корзины пока является рекомендацией.
  • Первый показ: законченная главная → связное русское демо → отдельное согласование компании. Красивый макет не подтверждает работу формы.
  • Сохранение: код/план — Git при настройке; БД/медиа — отдельные копии; личные отметки — экспорт JSON. Vercel только по желанию и после проверки приватности.

Гарантировать продажи или решение шефа невозможно. Этот план задаёт проверяемый путь к рабочему сайту и понятному собственному вкладу.

Карта результата

Основа → стиль и главная → каталог и услуги → заявка и показ → языки и проверка → согласованный запуск.

Каждый урок: одно действие → видимый результат → критерий проверки → короткое объяснение → заметка. Hermes проверяет результат и даёт только следующий шаг; сайт собираешь ты.

Без обнуления: ID шагов и формат экспорта сохранены. Инструкции обновлены, но старые галочки не доказывают выполнение новых критериев. Сохрани экспорт и сверяй отмеченные пункты с наставником, не перепроходи их автоматически.

Ближайший технический пункт: проверить REST-маршрутизацию существующей площадки перед редактированием. Успешный HTTP 200 с HTML вместо JSON не означает исправность REST.

Исследование: ключевые планы, брифы, аудит, презентация компании и публичный сайт. Это не заявление о прочтении каждого файла и архива. Подробности — разбор материалов.

В этом фильтре пока нет шагов.
