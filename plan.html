Как работать с планом — коротко

Новый старт, не уничтожение старого

Этот маршрут начинается с нуля. Старые проекты, исходники и принятые учебные задания остаются отдельно. Не импортируем весь старый сайт и не заставляем заново проходить общий курс.

Новая WordPress-среда ещё не создана. Тема, плагины, фактический адрес и хостинг проверяются на соответствующем шаге.

Одна сессия — видимый результат

Открой первый незавершённый шаг → сделай → проверь по критерию → оставь заметку → поставь галочку → экспортируй отметки. Если не получается — запиши конкретный блокер и попроси одно следующее действие.

План — основной журнал этого нового проекта. Mastery остаётся справочником, без автоматической синхронизации статусов.

  • Сейчас: русский сайт, каталог, услуги, телефон и заявка, оплата/получение на заводе.
  • Позже: основной LV, затем EN, затем RU; всё содержание и сообщения без смеси языков.
  • Не сейчас: онлайн-оплата, доставка, аккаунты, фильтры ради красоты, обязательный PHP-курс, конвейер из всех AI.
  • Моя рекомендация: одна ручная сборка Kadence + Gutenberg/Kadence Blocks; сначала проверить совместимость. Не обязательно переносить HTML в кастомную тему.
  • Первый показ: законченная главная → связное русское демо → отдельное согласование компании. Красивый макет не подтверждает работу формы.
  • Сохранение: код/план — Git при настройке; БД/медиа — отдельные копии; личные отметки — экспорт JSON. Vercel только по желанию и после проверки приватности.

Гарантировать продажи или решение шефа невозможно. Этот план задаёт проверяемый путь к рабочему сайту и понятному собственному вкладу.

В этом фильтре пока нет шагов.
